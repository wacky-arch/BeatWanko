# BeatWanko (Beat Saber 1.40.8 / 1.44.1)

Beat Saber 向けの **わんこそば式エンドレスチャレンジ MOD** です。1曲クリアするごとに次の曲を自動で連続出題し、未所持の譜面は BeatSaver から自動ダウンロード・読み込みします。

- **オンラインランキング**: https://beatwanko.pages.dev/
- **対応ゲームバージョン**: Beat Saber `1.40.8` / `1.44.1`（Steam / Meta PCVR 両対応）

## 4つのチャレンジモード

1. **ノーマル（Normal）**: 難易度・★・NPS・曲長を好みに合わせて絞り込める自由モード（`Failしても続ける` 設定可）
2. **無条件ランキング（Unconditional ☠️）**: 全モディファイア OFF 固定、全 BeatSaver 譜面からランダム出題（オンラインランキング対象）
3. **SSステップアップ（StepUp ⭐️）**: ★0〜1台から始まり、1曲ごとに ★帯が上がる全14曲完走チャレンジ（全モディファイア OFF 固定・オンラインランキング対象）
4. **耐久ランキング（Endurance 💪）**: NPS ≦ 8・ポーズ禁止・全モディファイア OFF 固定の耐久チャレンジ（オンラインランキング対象）

## 前提 MOD / Requirements

- **BSIPA** (`^4.3.0`)
- **BSML**
- **SongCore**
- **SongDetailsCache**

## インストール / Installation

GitHub Releases からお使いの Beat Saber バージョンに対応する ZIP をダウンロードして解凍し、中の `Plugins/BeatWanko.dll` を Beat Saber フォルダ（`Plugins/`）へ配置してください。

- **Beat Saber 1.40.8**: `BeatWanko_v1.1.7_bs1.40.8.zip`
- **Beat Saber 1.44.1**: `BeatWanko_v1.1.7_bs1.44.1.zip`
